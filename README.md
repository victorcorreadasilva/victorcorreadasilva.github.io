# Portfólio profissional — Victor Corrêa da Silva

Site estático em português para apresentar minha atuação com desenvolvimento .NET, trajetória profissional, competências e projetos públicos.

**Endereço:** [victorcorreadasilva.github.io](https://victorcorreadasilva.github.io/)

## Tecnologias do site

- HTML semântico
- CSS responsivo, com temas claro e escuro
- JavaScript sem bibliotecas
- Hospedagem GitHub Pages

O site não utiliza servidor, banco de dados ou etapa de compilação.

## Visualização local

Abra `index.html` no navegador. Se preferir um servidor local, execute na pasta do projeto:

```bash
python -m http.server 8000
```

E acesse `http://localhost:8000`.

## Como atualizar o portfólio

- Textos, links e seções: `index.html`
- Cores, fontes e responsividade: `styles.css`
- Menu móvel, troca de tema e animações: `script.js`
- Imagem de compartilhamento: `assets/og-preview.png`
- Ícone da aba: `assets/favicon.svg`

### Para acrescentar um projeto

1. Duplique o bloco `<article class="project-card">` no `index.html`.
2. Atualize título, descrição, tecnologias, funcionalidades e endereço do repositório.
3. Substitua a ilustração conceitual por uma captura real do novo projeto, caso tenha uma.
4. Confira também a contagem no bloco `project-end` e publique um commit.
